# RAG PDF Chatbot

A retrieval-augmented generation chatbot that answers questions grounded in uploaded PDFs, with cited source pages.

**Status:** 🚧 In progress

## Stack
- Python
- LangChain
- Chroma / Qdrant (vector store)
- Gradio (UI)
- Docker (deployment)

## Setup

```bash
git clone <your-repo-url>
cd rag-pdf-chatbot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # add your LLM API key
```
